SUPPORT

Support-key registration

Each registered user will have an individual customer reference, with aircraft-specific support keys for A319 Advanced and A350-1000 Advanced.

Registration is being prepared

The secure registration service is not connected yet. No personal information or support-key requests are collected through this page. Please do not post email addresses or keys in public GitHub issues.

How it will work

A user requests a support key, receives it privately and can quote the support ID when reporting a problem. No hardware fingerprint is required. The service will store only the information needed for support and registration.

For privacy information see the privacy notice.
