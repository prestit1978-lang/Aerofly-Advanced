# A319 / A350 Advanced

Independent aircraft systems enhancements for **Aerofly FS 4**.

## Aircraft
**A319 Advanced** — expanded systems, failures and operational procedures.

**A350-1000 Advanced** — enhanced aircraft systems, abnormal scenarios and dispatch-focused features.

Official website: https://prestit1978-lang.github.io/Aerofly-Advanced/
